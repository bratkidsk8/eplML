# Significado de las variables del dataset EPL
## English Premier League

Este dataset muestra datos de eventos crudos de la premier league desde el año 2000 hasta el 2025.

Las temporadas se juegan en un año de agosto-junio, la primera división se juega con 20 equipos y con una duración de 38 jornadas.

Análisis


| Atributo | Significado |
| :---: | :--- | 
| **Season** | Año en que inicia la temporadora y finalización del siguiente año|
| **MatchDate** | Fecha en la que se llevo acabo el partido   |
| **HomeTeam** | Equipo local   |
| **AwayTeam** | Equipo visitante   |
| **FullTimeHomeGoals** | Goles anotados por el equipo local   |
| **FullTimeAwayGoals** |  Goles anotados por el equipo visitante  |
| **FullTimeResult** | Resultado del equipo ganador: H si ganó el equipo local, A si ganó el equipo fuera de casa y D si hubo un empate   |
| **HalfTimeHomeGoals** | Goles del equipo local anotados en la primera mitad       |
| **HalfTimeAwayGoals** | Goles del equipo visitante anotados en la primera mitad   |
| **HalfTimeResult** | Goles anotados en la primera mitad  |
| **HomeShots** | Tiros totales del equipo local  |
| **AwayShots** | Tiros totales del equipo visitante  |
| **HomeCorners** | Corners totales del equipo local   |
| **AwayCorners** | Corners totales del equipo visitante  |
| **HomeFouls** | Faltas totales del equipo local   |
| **AwayFouls** | Faltas totales del equipo visitante  |
| **HomeYellowCards** | Tarjetas amarillas del equipo local   |
| **AwayYellowCards** | Tarjetas amarillas del equipo visitante   |
| **HomeRedCards** | Tarjetas rojas del equipo local   |
| **AwayRedCards** | Tarjetas rojas del equipo visitante    |
